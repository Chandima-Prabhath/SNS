# Adoo ASR Server — Python dependencies
# Install with: pip install -r requirements.txt
#
# These packages provide:
#   - fastapi + uvicorn: HTTP server
#   - python-multipart: for multipart/form-data file uploads
#   - onnxruntime: ONNX model runtime (CPU)
#   - soundfile + librosa: audio I/O and resampling
#   - numpy: array math
#   - fastrtc-moonshine-onnx: Moonshine ASR model wrapper
#
# Notes:
#   - ffmpeg must also be installed system-wide for librosa to decode MP3/Opus/WebM:
#       Ubuntu/Debian: sudo apt install ffmpeg
#       macOS:         brew install ffmpeg
#   - First run will download Moonshine weights from Hugging Face (~28MB for
#     tiny+quantized, ~109MB for tiny+float, cached in ~/.cache/huggingface).
